# Changelog

## 2.1.1

- Replace all emoji-based whale and achievement artwork with the plugin's bundled whale atlas, CSS-drawn achievement marks, and an original SVG whale silhouette for postcards.

## 2.1.0

- Make new tide moments visibly appear beside the floating whale with priority-aware, bounded presentation and quiet screen-reader behavior.
- Add a compact seven-day ocean journal, current whale story beat, lightweight cove preview, and field-backed Privacy Ledger.
- Add browser-local quiet, standard, and lively presentation preferences with safe storage fallback and system reduced-motion priority.
- Replace duplicate overlay/settings polling with one lifecycle-aware store that prevents stale reads from overwriting mutations.
- Split shared catalogs, view models, SVG export safety, preferences, and polling state into independently tested modules; add v3/v4 migration coverage.

## 2.0.0

- Add a 20-species whale manifest, Ocean Levels 1–100, per-species resonance, and safe visible tide reactions.
- Add bounded local tide moments, SVG postcard downloads, opaque live receipt digests, and v1–v4 state migration to the latest v5 state.
- Add a 24-item collectible catalog, eight fixed cove slots, room presets, gentle expeditions, and isolated visitor-bottle previews.
- Add explicit local whale-circle cards with preset aliases and coarse activity summaries. The feature has no account, ranking, networking, or arbitrary text transport.
- Preserve metadata-only observation, local storage, reduced-motion UI, and five-second polling. Backups omit session-derived receipt data and event contents.

## 1.0.0

- First release: privacy-safe metadata reducer, durable idempotent progress, XP/levels/streaks/statistics, 12 achievements, six skins, import/export/reset, draggable whale overlay, and Whale Home settings.
